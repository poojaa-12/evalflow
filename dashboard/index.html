Evalflow

Dependency-aware cache for a synthetic eval runner. Not a Nuro system and not a real autonomy stack. Numbers on this page come from the measured v1 and v2 runs.

What changed

v2 edits planner conservatism only. A scenario is recomputed when its depends_on list includes a changed component.

Invalidation

Cache key

sha256(evaluator_version + scenario_fingerprint + hashes of depends_on components only)

Fingerprint and each component hash are sha256 of canonical JSON (sort_keys, compact separators). Components outside depends_on are not in the preimage, so an unrelated edit cannot change the key or the metrics.

Bench

Fresh cache, one v1 warmup, then 3 repeats. Each repeat copies the v1 cache, times a v2 run, and times a v2 run with the cache disabled. Speedup is median naive / median incremental. Workers 4, cost 0.1 s.

Comparator

Join on scenario id. Pass true to false is a regression. min_distance_m worsens if the candidate is lower by more than 0.05. jerk worsens if the candidate is higher by more than 0.10. A row that improves one metric and regresses another counts as a regression. Inside both tolerances, with no pass flip, the row is unchanged.
